### 加载机制（重要约定）
所有页面加载顺序：`common.css` →（页面内联 `<style>`）→ `theme-mist.css`。
把皮肤放在最后加载，用「同优先级后写覆盖」改皮，**不动原布局**，也避免去改 8 个页面各自内联的重复样式。
`reviews.html` 是自包含页（不引用 common.css），也因此自动被覆盖。

### theme-mist.css 做了什么
1. `:root` 重写色板：`--surface` 改为玻璃层；强调色 `#ff6b35 → #c9714c`（柔雾陶土）、`#ff8f6a → #e0a288`；文字改暖灰绿 `#1f2520/#4b544c/#79827a`。
2. 背景两层伪元素：`body::before`（fixed，照片，`filter:saturate(.62) contrast(.94) brightness(1.06)`，`center 22% / cover`）+ `body::after`（fixed，纱罩：顶部淡出 + 两个白色径向 + 浅绿线性渐变 + SVG 颗粒噪点 `feTurbulence`）。
3. 玻璃拟态：大面（header/`.surface`/卡片/面板/modal/footer/购物车面板）统一 `backdrop-filter:blur(20px) saturate(.96) brightness(1.05)` + 1px 高光边 + 柔和阴影；中小控件走 `blur(11px)`；首页 `.nav-card` 改半透明深玻璃。
4. 弹层遮罩、状态标签（`.cond-new/.cond-old/.status.*`）、输入框聚焦态改低饱和半透明。
5. `@supports not (backdrop-filter)` 降级：玻璃变实（alpha ≈ .9）。`max-width:640px` 时背景改 `scroll`。

### ⚠️ 踩坑（务必记住）
**`html` 上不能设背景色，`body` 也必须 `background:transparent`。**
`body::before/::after` 用 `z-index:-2/-1`，因为 body 不是层叠上下文，它们会参与**根**层叠上下文，绘制顺序在「根上下文的非定位块级后代背景」**之前** → 只要 body 自己画底色（或 html 带背景导致 body 背景不再上提到 canvas），照片就会被整块盖住，只剩视口边缘几像素。排查花了 3 轮截图才定位。
