## 首页汉堡面板三张卡片：镜面高光（Specular）
- 新增 `specular.js`：把参考的 `SpecularButton`（React + ogl）**用无依赖 WebGL2 原生移植**，无构建、可离线。
- 对 `.nav-card` 逐个注入 `<span class="specular-fx"><canvas></canvas></span>`，SDF 圆角矩形 + 高斯线 + 椭圆法线镜面，`gl_FragCoord` 计算；混合 `ONE / ONE_MINUS_SRC_ALPHA`、清屏透明。
- 无依赖要点：全屏三角形（`[-1,-1, 3,-1, -1,3]`），手写 `compile/attach/link`，`ResizeObserver` 同步尺寸，`uCenter=(PAD+w/2, PAD+h/2)*dpr`（画布上下留白对称，无需翻转 Y）。
- 主题呼应：`lineColor:#ff8f6a`（主题 --accent-light 暖橙）、`baseColor:#5a5370`；常态微弱高光（idle 0.22）+ 靠近光标增强，光源方向随指针转动。
- 性能与无障碍：面板收起（`.site-header` 无 `menu-open`）或 `document.hidden` 时跳过绘制；`prefers-reduced-motion` 下只画一帧静态高光、不做动画。
- 画布 `inset:-14px`，与 `.card-nav-panel` 的 `padding:14px` 对齐以免高光被裁切；文字层 `z-index:1`，画布 `z-index:0`。
- 仅首页有卡片，故 `specular.js` 只在 `index.html` 引用。
